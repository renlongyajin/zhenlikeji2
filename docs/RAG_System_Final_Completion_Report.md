## 📋 项目概述

本项目成功开发并交付了一套基于RAG（Retrieval-Augmented Generation）和ReAct（Reason+Act）架构的智能问答系统。系统专门用于处理医学文献，提供高质量的智能问答服务，具备完整的容器化部署能力和友好的Web界面。
