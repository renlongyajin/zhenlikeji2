## 🚀 快速使用

### 1. 初始化环境
```bash
# 初始化数据卷目录
./scripts/init_volumes.sh

# 启动Docker服务（如果尚未启动）
docker-compose up -d
```

### 2. 备份当前数据
```bash
# 一键备份所有数据
./scripts/backup_data.sh

# 备份文件将保存在 ./backups/ 目录
```

### 3. 分享给他人
```bash
# 创建共享数据包
./scripts/share_data.sh

# 会生成一个包含所有数据和安装脚本的压缩包
# 他人收到后只需运行 ./install.sh 即可
```

### 4. 在新环境恢复
```bash
# 从备份文件恢复数据
./scripts/restore_data.sh -f backups/backup_file.tar.gz

# 启动服务
docker-compose up -d
```

## 🔧 技术特点

### 数据持久化优化
- **本地卷绑定**：使用bind mounts替代匿名卷，数据更安全
- **统一命名规范**：所有数据卷使用统一的命名和标签
- **权限管理**：自动设置正确的文件权限和SELinux上下文

### 备份功能
- **全量备份**：备份所有数据库（PostgreSQL、Elasticsearch、Milvus、MinIO、etcd）
- **智能检测**：自动跳过未运行的服务
- **数据校验**：生成MD5校验和确保数据完整性
- **自动压缩**：使用gzip压缩减少存储空间
- **定期清理**：自动删除7天前的旧备份

### 恢复功能
- **一键恢复**：自动按依赖顺序恢复所有组件
- **完整性验证**：恢复前后验证数据完整性
- **服务重启**：自动重启相关服务确保数据生效
- **错误处理**：提供详细的错误信息和恢复建议

### 共享功能
- **一键打包**：自动创建包含所有必要文件的共享包
- **云存储支持**：支持AWS S3、阿里云OSS、MinIO
- **完整性验证**：包含数据验证脚本
- **一键安装**：提供简单的安装脚本给接收方
