**定义**: 检索到的上下文与用户查询的相关程度

**评估结果**:

```
低相关 (0.5-0.7): 6.7% (30个)
无关 (0.0-0.5): 0.0% (0个)
```

**评估方法**:
```python
def evaluate_context_relevancy(query, retrieved_docs):
    """
    使用BERT模型计算查询与文档的语义相似度
    结合关键词匹配和语义理解
    """
    scores = []
    for doc in retrieved_docs:
        # 语义相似度计算
        semantic_score = calculate_semantic_similarity(query, doc['content'])

        # 关键词匹配度
        keyword_score = calculate_keyword_overlap(query, doc['content'])

        # 综合评分
        final_score = 0.7 * semantic_score + 0.3 * keyword_score
        scores.append(final_score)

    return np.mean(scores)
```
